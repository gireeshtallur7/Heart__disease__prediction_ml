## 📌 Overview

This project predicts the likelihood of heart disease in patients using **Machine Learning**. A web app is built using **Streamlit** for real-time predictions.

**Achievement:** 86% accuracy using Logistic Regression

## 🎯 Key Features

- ✅ Predicts heart disease risk based on patient clinical data
- ✅ Compares 4 supervised learning algorithms
- ✅ Interactive web app interface
- ✅ Real-time predictions
- ✅ Easy to use for non-technical users

## 🧠 Algorithms Compared

| Algorithm | Accuracy |
|-----------|----------|
| **Logistic Regression** | **86%** (Best) |
| Support Vector Machine (SVM) | 83% |
| Decision Tree | 78% |
| Naïve Bayes | 81% |

## 📊 Dataset Features

The model uses 13 clinical features:

| Feature | Description |
|---------|-------------|
| age | Age in years |
| sex | Male/Female |
| cp | Chest pain type |
| trestbps | Resting blood pressure |
| chol | Serum cholesterol |
| fbs | Fasting blood sugar |
| restecg | Resting ECG results |
| thalach | Maximum heart rate |
| exang | Exercise induced angina |
| oldpeak | ST depression |
| slope | Slope of peak exercise ST |
| ca | Number of major vessels |
| thal | Thalassemia |
